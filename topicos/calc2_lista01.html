0. Tabela de Integrais e Derivadas Imediatas

Base de tudo o que vem a seguir — memorize estas antes de tentar qualquer técnica mais avançada. Toda técnica (partes, trig, substituição trigonométrica, frações parciais) serve apenas para reduzir uma integral difícil a uma destas formas imediatas.

Derivadas imediatas

d/dx(xn) = n·xn−1
d/dx(ex) = ex   d/dx(ax) = axln a
d/dx(ln x) = 1/x
d/dx(sen x) = cos x   d/dx(cos x) = −sen x
d/dx(tg x) = sec²x   d/dx(cotg x) = −cossec²x
d/dx(sec x) = sec x·tg x   d/dx(cossec x) = −cossec x·cotg x
d/dx(sen−1x) = 1/√(1−x²)   d/dx(cos−1x) = −1/√(1−x²)
d/dx(tg−1x) = 1/(1+x²)   d/dx(sec−1x) = 1/(|x|√(x²−1))
d/dx(senh x) = cosh x   d/dx(cosh x) = senh x
d/dx(tgh x) = sech²x

Integrais imediatas — formas básicas

∫k dx = kx + C
∫xn dx = xn+1/(n+1) + C, n≠−1
∫dx/x = ln|x| + C
∫ex dx = ex + C   ∫axdx = ax/ln a + C
∫sen x dx = −cos x + C   ∫cos x dx = sen x + C
∫sec²x dx = tg x + C   ∫cossec²x dx = −cotg x + C
∫sec x·tg x dx = sec x + C   ∫cossec x·cotg x dx = −cossec x + C
∫tg x dx = ln|sec x| + C   ∫cotg x dx = ln|sen x| + C
∫sec x dx = ln|sec x + tg x| + C
∫cossec x dx = −ln|cossec x + cotg x| + C

Envolvendo a²±x² e x²−a² (essenciais para substituição trigonométrica)

∫dx/(a²+x²) = (1/a)·tg−1(x/a) + C
∫dx/√(a²−x²) = sen−1(x/a) + C
∫dx/√(a²+x²) = ln(x+√(a²+x²)) + C = senh−1(x/a)+C
∫dx/√(x²−a²) = ln|x+√(x²−a²)| + C
∫dx/(x√(x²−a²)) = (1/a)·sec−1|x/a| + C
∫√(a²−x²) dx = (x/2)√(a²−x²) + (a²/2)sen−1(x/a) + C

Reduções por partes (base do "macete cíclico" e "tabular")

∫f g' dx = fg − ∫f' g dx
∫xeaxdx = eax(ax−1)/a² + C
∫eaxsen(bx)dx = eax(a·sen bx − b·cos bx)/(a²+b²) + C
∫eaxcos(bx)dx = eax(a·cos bx + b·sen bx)/(a²+b²) + C
∫ln(ax) dx = x ln(ax) − x + C
∫sen−1x dx = x sen−1x + √(1−x²) + C

Reduções trigonométricas (potências)

∫sennax dx = −senn−1ax·cos ax/(na) + (n−1)/n ∫senn−2ax dx
∫cosnax dx = cosn−1ax·sen ax/(na) + (n−1)/n ∫cosn−2ax dx
∫tgnx dx = tgn−1x/(n−1) − ∫tgn−2x dx, n≠1
∫secnx dx = secn−2x·tg x/(n−1) + (n−2)/(n−1)∫secn−2x dx

1. Integração por Partes

A fórmula: ∫u dv = uv − ∫v du.

O macete (regra LIATE): escolha u seguindo a prioridade Logarítmica > Inversa trigonométrica > Algébrica (polinômio) > Trigonométrica > Exponencial. Quem aparece primeiro nessa lista vira u; o resto (junto com dx) vira dv. Motivo: ln e arc-funções não têm antiderivada simples, então é melhor derivá-las (elas viram algo mais simples); exponenciais e trigonométricas são fáceis de integrar repetidamente, então é melhor jogá-las para dv.

Método tabular (quando u é polinômio): monte duas colunas — D (derivadas sucessivas de u até chegar a 0) e I (integrais sucessivas de dv) — e some os produtos diagonais com sinais alternados +, −, +, −, .... Isso substitui repetir "por partes" várias vezes.

Caso cíclico (eax·sen/cos): aplicar partes duas vezes traz a integral original de volta. Chame a integral de I, isole I algebricamente dos dois lados da equação.

  • = −2x cos(x/2) + 2∫cos(x/2) dx
= −2x·cos(x/2) + 4·sen(x/2) + C

2. Integrais Trigonométricas

O macete central: olhe a paridade dos expoentes.

∫senmx cosnx dx — se m é ímpar, separe um fator sen x, troque o resto senparx = (1−cos²x)... e substitua u=cos x. Se n é ímpar, faça o espelho: separe cos x, use cos²x=1−sen²x, u=sen x. Se ambos pares, não há substituição direta — use as identidades de redução de potência: sen²x = (1−cos2x)/2, cos²x = (1+cos2x)/2.

∫tgmx secnx dx — se n é par (≥2), separe sec²x, escreva o resto secparx=(1+tg²x)..., substitua u=tg x. Se m é ímpar, separe sec x·tg x, escreva tgparx=(sec²x−1)..., substitua u=sec x. Se m par e n ímpar, use a fórmula de redução para secnx (integração por partes escondida). Mesma lógica vale para cotg/cossec, trocando os papéis.

Produtos sen(ax)cos(bx), sen(ax)sen(bx), cos(ax)cos(bx) com a≠b: nunca por partes — use as fórmulas de produto-para-soma (tabela, item 69).
7e ∫sen³x dx — potência ímpar de seno
  • sen³x = sen x·(1−cos²x); u=cos x, du=−sen x dx
= −cos x + cos³x/3 + C
7g ∫sen⁵x dx — mesma ideia, potência maior
  • sen⁵x = sen x(1−cos²x)²; u=cos x
= −cos x + (2/3)cos³x − (1/5)cos⁵x + C
7j ∫sen³x cos³x dx — ambos ímpares: escolha qualquer um para sobrar
  • sen³x = sen x(1−cos²x); u=cos x
  • = −∫(1−u²)u³ du = −u⁴/4 + u⁶/6
= cos⁶x/6 − cos⁴x/4 + C
7k ∫cos³(2x)sen⁵(2x) dx — cos ímpar, mesmo com argumento 2x
  • cos³(2x)=cos(2x)(1−sen²2x); u=sen(2x), du=2cos(2x)dx
= sen⁶(2x)/12 − sen⁸(2x)/16 + C
7u ∫sec²x·tg x dx — u=tg x direto
= tg²x/2 + C
7w ∫sec³x·tg x dx — m=1 ímpar: separe sec·tg, u=sec x
= sec³x/3 + C
7x ∫sec⁴x·tg²x dx — n=4 par: separe sec², u=tg x
  • sec⁴x=(1+tg²x)sec²x; ∫(1+u²)u² du
= tg³x/3 + tg⁵x/5 + C
7z ∫_(π/4)^(π/2) cossec⁴x dx — espelho de sec par: separe cossec², u=cotg x
  • cossec⁴x=(1+cotg²x)cossec²x → −∫(1+u²)du = −cotg x − cotg³x/3
  • Em π/2: 0. Em π/4: −(1+1/3)=−4/3
= 0−(−4/3) = 4/3
7α ∫sec⁶x dx — n=6 par
= tg x + (2/3)tg³x + (1/5)tg⁵x + C
7β ∫tg⁵x dx — potência ímpar de tg: tg⁵x=tg³x(sec²x−1), reduz recursivamente
  • ∫tg³x sec²x dx = tg⁴x/4
  • ∫tg³x dx = tg²x/2 − ln|sec x|
= tg⁴x/4 − tg²x/2 + ln|sec x| + C
7q ∫₀^(2π) √[(1−cos x)/2] dx — identidade de arco-metade: (1−cosx)/2 = sen²(x/2)
  • √[...] = |sen(x/2)|; em [0,2π], x/2∈[0,π] ⇒ sen(x/2)≥0
= ∫₀^(2π) sen(x/2)dx = [−2cos(x/2)]₀^(2π) = 4
7r ∫₀^π √(1−cos2x) dx — 1−cos2x = 2sen²x
= √2∫₀^π|senx|dx = √2·2 = 2√2
7s ∫₀^π √(1−sen²t) dt = ∫₀^π|cos t|dt — cuidado: cos t troca de sinal em π/2

3. Substituição Trigonométrica

O macete: olhe qual expressão quadrática aparece dentro da raiz (ou no denominador) e escolha a substituição que a transforma num quadrado perfeito via identidade pitagórica.
Você vê...SubstituaViraIdentidade
a² − x²x = a·senθa·cosθ1−sen²θ=cos²θ
a² + x²x = a·tgθa·secθ1+tg²θ=sec²θ
x² − a²x = a·secθa·tgθsec²θ−1=tg²θ

Depois de resolver em θ, monte um triângulo retângulo com os lados x, a e a hipotenusa/cateto correspondente para "traduzir" a resposta de volta para x (ou use as identidades secθ=x/a etc.). Antes de tudo, sempre cheque se um truque algébrico mais simples resolve (como dividir polinômios, ou uma substituição u comum) — trig substitution é o último recurso quando a raiz não sai de outro jeito.

4. Frações Parciais

O macete: fatore o denominador e escreva um termo por fator, seguindo as 4 regras:

5. Integrais Impróprias

Duas situações tornam uma integral "imprópria":
(1) Limite infinito — troque ∞ por um parâmetro b e calcule o limite: ∫ₐ^∞ f dx = limb→∞ ∫ₐ^b f dx.
(2) Descontinuidade no integrando (dentro do intervalo ou num extremo) — isole o ponto ruim c com um parâmetro que tende a c e calcule o limite lateral: ∫ₐ^c f dx = limt→c⁻∫ₐ^t f dx.

Se o limite existir (finito) ⇒ a integral converge. Se não existir (±∞ ou oscila) ⇒ diverge.

Quando não dá para calcular exatamente, use os testes de comparação: p-teste (∫₁^∞ dx/xp converge se p>1, diverge se p≤1; e ∫₀¹dx/xp converge se p<1) e comparação direta/limite: se 0≤f≤g e ∫g converge, ∫f converge; se f≥g≥0 e ∫g diverge, ∫f diverge.
16 ∫₁^∞ ln(x)/x² dx — a área é finita? — limite infinito + por partes
  • u=ln x, dv=dx/x² ⇒ v=−1/x
  • = [−ln x/x]₁^∞ + ∫₁^∞ dx/x²
  • limb→∞ (−ln b/b) = 0 (ln b cresce mais devagar que b, regra de L'Hôpital)
  • ∫₁^∞ dx/x² = 1
Sim, é finita: valor = 1

20 Lata de tinta infinita: y=1/x, x∈[1,∞), girada em torno do eixo x — o paradoxo do pintor
  • (a) Área da superfície: S=2π∫₁^∞(1/x)√(1+1/x⁴)dx ≥ 2π∫₁^∞ dx/x = 2π·lim ln(b) → diverge
  • (b) Volume: V=π∫₁^∞(1/x)²dx = π[−1/x]₁^∞ = π
Superfície infinita, mas volume finito = π (o "paradoxo": a lata teria volume finito π mas não haveria tinta suficiente no universo para pintar sua superfície — na prática o paradoxo se resolve porque uma camada de tinta física tem espessura mínima).
